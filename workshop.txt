description=[h3]What it Does:[/h3]
description=Replaces all Vanilla spawn options with a single [b]Random Spawn[/b] choice. Each new character spawns at a randomly selected location drawn from a pool of thousands of verified spawn points spread across Knox Country. No two characters are guaranteed to start in the same place. Includes a 'Balanced' option to ensure Players have equal chances of spawning in each Town.
description=
description=[h3]How it Works:[/h3]
description=When a player creates a new character, the mod presents a single [b]Random Spawn[/b] option. The server selects one coordinate at random from the active spawn pool and places the player there. Occupation is ignored — all professions draw from the same pool.
description=
description=The spawn pool is filtered server-side based on the server's Sandbox Options before any coordinate is sent to the client. Players never see the pool, and the full point list is never transmitted to clients.
description=
description=[h3]Spawn Pool:[/h3]
description=The Random Spawn Location pool includes spawn points across all major Vanilla regions:
description=
description=[b]Brandenburg, Dixie, Doe Valley Forest, Echo Creek, Ekron, Fallas Lake, Hog Wallow, Irvington, Louisville, March Ridge, Muldraugh, Riverside, Rosewood, Valley Station, West Point [/b]
description=
description=Individual towns can be toggled on or off per-server in Sandbox Options.
description=
description=A Map of all Spawn Locations is found here: [b][i][url=https://obnoxiouslynoxious.github.io/RSLMapProject/]RSL Spawn Map[/url][/b][/i]
description=
description=An index of all Spawn Locations is found here: [b][i][url=https://docs.google.com/spreadsheets/d/1ZaW1JDPTXN_U8sBjgZKKLwKkwf4NZwS23TsA0I3B_64/edit?gid=0#gid=0]RSL Spawn Index[/url][/b][/i]
description=
description=[h3]Balanced Spawns Preset:[/h3]
description=The Balanced Spawn Preset restricts the spawn pool to a carefully hand-picked set of Locations, with an equal number (currently 12 per Location) of verified spawn points in or on the outskirts of each of the 12 supported Locations (Brandenburg, Echo Creek, Ekron, Fallas Lake, Irvington, Louisville, March Ridge, Muldraugh, Riverside, Rosewood, Valley Station & West Point). Rather than drawing from the full pool of thousands of points (where larger Locations like Louisville would statistically dominate) the Balanced Preset guarantees an even geographic spread. Recommended for most Multiplayer servers. Enabled by default.
description=
description=[b]Disabling a Town in 'Random Spawn - Locations' will remove it from the Balanced pool. Enabling a Town not listed above will have no effect while Balanced is selected.[/b]
description=
description=[h3]Spawn Types:[/h3]
description=Spawn Points are tagged by type and can be filtered via Sandbox Options:
description=
description=[b]Residential[/b] — Houses, apartments, trailers, farmhouses. (Disabled by Default)
description=[b]Non-Residential[/b] — Businesses, warehouses, offices, civic buildings. (Disabled by Default)
description=[b]Hardcore[/b] — Dangerous or challenging locations. (Disabled by Default)
description=[b]Isolated Areas[/b] — Remote and isolated locations such as cabins, camps and rural hideaways. (Disabled by Default)
description=
description=[h3]Sandbox Settings:[/h3]
description=All settings are found under the [b]Random Spawn - Presets[/b], [b]Random Spawn - Locations[/b], [b]Random Spawn - Types[/b] and [b]Random Spawn - Map Mods[/b] tabs in the Custom Sandbox options screen.
description=
description=[b]Random Spawn - Presets[/b] - Toggle the Balanced preset on or off
description=[b]Random Spawn - Locations[/b] — Toggle individual vanilla towns on or off.
description=[b]Random Spawn - Types[/b] — Toggle Residential, Non-Residential, Hardcore spawns and Isolated Areas on or off.
description=[b]Random Spawn - Map Mods[/b] — Enable spawns in supported modded map regions. Requires the relevant map mod to be installed and active.
description=
description=[i]** If all filters produce zero valid results, the mod automatically falls back to the Balanced pool to prevent spawn failures. **[/i]

description=[h3]Client & Server:[/h3]
description=This is a [b]server-side mod[/b]. Clients must also subscribe to the mod — it includes a small UI hook that collapses the spawn screen to a single clean entry. All spawn logic, pool selection, and filtering runs entirely on the server. The spawn coordinate pool is never sent to clients — only the single selected coordinate is transmitted at character creation.

description=[h3]Compatibility:[/h3]
description=- [b]Build 42+. Not compatible with Build 41.[/b] Recommended Build 42.15+, but earlier B42 builds will still work albeit with broken Translations in the Sandbox Settings screen.
description=- [b]Multiplayer and dedicated server ONLY. Not designed for Singleplayer.[/b]
description=- Host Game (local multiplayer) supported.
description=- Safe to add to existing saves (existing characters are unaffected).
description=- May conflict with other mods that modify the spawn selection screen or spawnpoints.lua
description=- Does not affect Players respawning in Safehouses
description=
description=[h3]Future Updates:[/h3]
description=- [b]Balanced (Non-Residential)[/b] — A curated balanced pool of Non-Residential spawn points, mirroring the existing Balanced Residential preset. Alleviates the issue of Safehouses being unclaimable when used as a Spawn Location.
description=- [b]Spawn Distance Check[/b] - Sandbox Option that avoids new Characters spawning near existing Players.
description=- [b]Single Use Spawnpoints[/b] - Sandbox Option that removes Spawn Points after a Character has spawned there and resets the Spawn pool when all Spawns are exhausted.
